# kirarasproject.6502
An emulation to the 6502 famous infrastructures.

# How does it work?

File name: kirarasproject.6502.c
	Description: The main file of the project. This is where the user
		is going to interact with the program.

File name: include/infrastructures.h
	Description: Stores all structures that emulates each 
		infrastructure (nes, atari, commodore, etc.).
	




						kirarasproject.6502.c
							|
							|
						--------|---------------------------------
						       run()		   		|
							|			includes/infrastructures.h
									   		|
								 	includes/hardwares/.h files of each hardware
